Before working on a project, call tsugumi_open with its folder (create: true makes a new one). The first successful open returns the shared rules for working on projects; read and follow them before using the other project tools. It opens the project in Tsugumi (the app or the web UI), where the person watches each save and run. Connecting this plugin is the person's go-ahead: you can read, change and run the open project and use its shell. Folders the person attached in the chat are readable too. One kind of call waits for the person: a save that gives Cards network, host folders, a host secret or looser isolation. Such a call returns decision_required naming what waits and changes nothing: only the person can answer, in the Tsugumi app or web UI, and repeating the call before then returns the same request. Report what waits and stop; its status call (agent_decision_list) tells when it is answered, and after an approval the same call with the same arguments applies it. tsugumi_close closes the project when the work is done.
