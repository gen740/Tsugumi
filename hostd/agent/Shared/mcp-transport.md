Before working on a project, call tsugumi_open with its folder (create: true makes a new one). The first successful open returns the shared rules for working on projects; read and follow them before using the other project tools. It opens the project in Tsugumi (the app or the web UI), where the person watches each save and run. Connecting this plugin is the person's go-ahead: you can read, change and run the open project and use its shell. Folders the person attached in the chat are readable too. A few calls wait for the person: a save that gives Cards network, host folders, a host secret or looser isolation, and deleting run scratch. Such a call returns decision_required naming what waits; the request stays open in the Tsugumi app and web UI until the person answers, also when one opens later. Then call the same tool again with the same arguments.
