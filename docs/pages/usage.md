# 操作ガイド

## 画面からの基本操作

詳しい画面構成と仕様は [ui-view.md](ui-view.md) にまとめています。UI の表示言語は日本語がデフォルトで、設定の「一般 > 言語」から English に切り替えられます（アプリの再起動後に反映されます。英訳テーブルは `macOS/Resources/tools/en_strings.py`）。

1. **初回の環境準備**
   この Mac で仮想マシンを利用できない場合や、アプリ内に VM イメージが見つからない場合にのみ、メインウインドウに初期設定画面が表示されます。通常の初回準備（VM の起動ディスクの展開、Nix store 用ディスクの作成・初期化、VM の起動、VM の中で Tsugumi を Nix で組み立てる）は最初にプロジェクトを開いたタイミングで自動的に行われ（組み立ては初回とアプリの更新後だけで 1 分ほど。依存は VM の中で cache.nixos.org から取得し、Mac には何もダウンロードしない）、鳥のアニメーションとともに進行段階が表示されます。メニューの「ウインドウ > 実行環境のコンソール」（`⌥⌘K`）または画面上の「コンソールで詳細を見る」から、VM の起動ログをリアルタイムに確認できます。
2. **ホームとデモ**
   ホーム画面から新規プロジェクトの作成、既存フォルダの読み込み、最近使ったプロジェクトの再オープンを行えます。同梱デモは「コピーを開く」を選ぶと、`~/Documents/Tsugumi/<demo>` に編集可能なコピーが作られて開きます（同梱の原本は変更されません）。ホームの「Tsugumi を知る」（メニューの「ヘルプ > Tsugumi を知る」）は、[作った人](author.md)・README.md の課題の節・[なぜ作ったか](philosophy.md)・[名前の由来](name.md)を、そのままの文章で読む窓です。「読む」ではスクロールに合わせて一本の糸が段落を縫って進み、図（安田講堂、人と AI の間の壁、Cas A のスケッチが Draft になって動くまで、名前の由来）が文中で動きます。「カード」では一段落ずつ図と並べて見せ、→・Space・クリックで次へ進むと図が時間に沿って動きます（画面収録向け）。環境の起動やプロジェクトの読み込み中は進捗が表示され、失敗した際は原因・復旧手順・環境ログへの導線と再試行ボタンが表示されます。
3. **ワークベンチの構成**
   画面は大きく 4 つの領域に分かれています。
   - **左（サイドバー）**：Workflow の階層、Card の定義一覧、現在表示中の Card 一覧
   - **中央（Canvas）**：Card の配置と配線、出力のプレビュー
   - **下（ボトムパネル）**：状態バー、全体ログ、実行タイムライン
   - **右（インスペクタ）**：Agent とのチャット
   子 Workflow（Card in Card）はダブルクリックで同じタブのまま中へ入れます。サイドバーの階層一覧を右クリックすれば、別タブや別ウインドウとして開くこともできます。なお、どの階層を表示していても「実行」の対象は常にプロジェクト全体の Workflow です。
4. **Canvas での編集**
   Card の追加、ドラッグによる移動（グリッド吸着）、複製（`⌘D`）、削除、折りたたみのほか、出力ポートから入力ポートへのドラッグによる配線、線の選択と切断、`Shift` + ドラッグによる範囲選択、パン・ピンチ（または `⌘` + スクロール）による拡大縮小、全体表示・自動整列を行えます。
   Draft は `E` で置き、カードに内容を直接書きます（名前はなくても構いません）。線はカードのどこに落としてもつながり、ポートは線に合わせて作られます（設定は右クリックの「設定…」から）。
   入力値 Card は Canvas 上で直接値を書き換えられます。また、見た目としてまとめるグループ、Markdown で記述できる付箋、Card の出力を独立して並べる出力表示枠を配置できます。Canvas 上部には実行・停止ボタンや経過時間・進捗・問題一覧が並び、Draft があるときは右上に「Card を生成」が表示されます。
5. **Card のコンテキストメニュー（右クリック）**
   設定を開く、実行履歴、成果物、ログ、チャットへの参照追加、ここから実行、複製、折りたたみ、出力表示の切り替え、グループ化、配線の切断、削除を選べます。
6. **Card 設定ウインドウ**
   Card の種類に応じて「一般」「Nix 定義」「ソース（ファイルの作成・名前変更・削除に対応）」「入出力」「実行履歴」「成果物」「追加コンテキスト」の各画面を切り替えて編集します。設定ウインドウ内の編集は作業コピーとして保持され、「適用」（または「閉じる」）を押した時点で Workflow に反映・保存されます。Draft Card の場合は専用画面が開き、名前・概要・処理内容・仮の入出力ポート（仮の出力は `_outputs.fbs` となり、実装前に下流へ配線可能）を編集できます。
7. **保存と同期**
   状態バーには Workflow の実行状態と保存・同期状態が分けて表示されます。実行中は計算定義を変える編集やプロジェクトの切り替えが制限されますが、進行状況・履歴・成果物の閲覧はそのまま続けられます。
8. **Agent チャット**
   会話セッションの一覧と全文検索、Card や可視化枠の参照添付、`$` による Skill（プロジェクト内の `skills/` や設定で登録したフォルダ）の呼び出し、モデルの切り替え、メッセージの送信・応答の停止（Workflow 実行の停止とは独立）、再試行、会話の要約圧縮を行えます。チャットパネルを別ウインドウとして切り出すことも可能です。
9. **設定**
   プロジェクト単位の設定（プロジェクト名・実行環境、Canvas の流れの向き、データベース接続先、実行履歴、ビルドキャッシュ）と、アプリ全体の設定（言語・並列実行数・送信キー、外観テーマ・グリッド・アニメーション、エディター、キーボードショートカット、Skills、API キー、外部接続）を管理できます。
10. **状態の復元**
    Card の配置・付箋・グループ・出力表示枠はプロジェクトの `layout.json` に、カメラ位置（表示範囲・倍率）と選択状態は `ViewSave` によってビューごとに保存され、次回プロジェクトを開いたときにそのまま復元されます。

## 同梱デモと確認できる動作

各デモの Card のつながりと、それぞれの Card がしていることは[同梱デモのしくみ](demos.md)にまとめています。

| デモ | 試せる操作 | 確認できる結果 |
| --- | --- | --- |
| **データからレポートへ**（`report`） | そのまま実行する。`settings` の `seed` や `heading` を変えて再実行する。`aggregate` の `fail_on_purpose` を On にして実行し、Off に戻して `aggregate` だけを単体再実行する。`archive` をダブルクリックして子 Workflow に入り、成果物をプレビュー・書き出す | 同じ `seed` なら常に同じ集計結果になり、`heading` の変更がレポート見出しに反映される。意図的に失敗させると `aggregate` のエラーログに理由が出て下流の `render` は `blocked` になる。単体再実行では保存済み入力を使って即座に成功する。生成されたディレクトリ成果物は環境を初期化しても残る |
| **Collatz (C++ / Python)**（`collatz`） | そのまま実行する。`initial` の初期値や、各言語側の `check` の `maxRuns`（反復上限）を変更して実行する | 初期値 `27` は 111 ステップ（初期値を含め 112 個の値）で `1` に到達し、`compare` が C++ と Python の完全一致を報告する。`maxRuns` を小さくすると反復上限（`execution_limit`）で止まり、`3n+1` が 64 bit 整数を超える初期値では `integer overflow` を検出する。初期値 `2` では奇数側（`triple`）が `skipped` になる |
| **Plots**（`plots`） | そのまま実行する。`settings` の `seed`・`walkers`・`steps` や、`diffusion` の `frames`（アニメーションのコマ数）を変えて再実行する。`explore`・`spread` の表示を拡大してズーム・ホバーする | ウィンドウ向けに書いた matplotlib のコードがそのまま Card の表示に描かれる。`summary` は `plt.show()` で 400 本のランダムウォークのうち 40 本の軌跡と、全体の最終位置の分布（正規分布との比較）を示し、`diffusion` は `FuncAnimation` で広がりが √t で増える様子をライブで再生する。`explore`（Plotly）と `spread`（Altair）は対話できるグラフで、ウォーカーごとの値や平均二乗距離を確かめられる |
| **Cas A · Chandra RGB**（`casa`） | そのまま実行する。`bands` の帯域や `rgb` の `percentile`・`q` を変えて、その Card だけを実行し直す。`load` の `obsid`・`file`・`hash` を ObsID 114（50 ks、520 MB の深い観測）に変える。`spectrum` の範囲や刻み（`min_ev`・`max_ev`・`bin_ev`）を変える | 最初の実行で観測（ObsID 25628、13 MB）を Nix が 1 度だけ取得し、以後はストアのファイルを使う。`bands` が帯域ごとの光子数（赤 101,187 / 緑 157,471 / 青 110,852）を表で示し、`rgb` が Cas A を中心にした 360×360 の RGB 画像を表示する。`spectrum` は同じ光子のエネルギースペクトルを matplotlib で描き、3 帯域を色で塗って Mg・Si・S・Ar・Ca・Fe の輝線に印を付ける（緑の帯域が Si の輝線を含むことが分かる） |
| **科学デモ**（`gw150914`・`protein-6lu7`・`exoplanet-transit`・`seismic-trench`） | そのまま実行する（`load` が公開元からデータを取得するため、ネットワークへのアクセスを許可した Card を含む）。途中の Card のパラメータを変えて、その Card だけを実行し直す | 取得したファイルの大きさと SHA-256 が表示され、重力波のチャープ、タンパク質の結合ポケット、トランジットの折りたたみ、震源断面と b 値が図で表示される |
| **Draft 版**（`casa-draft` ほか、名前が `-draft` のもの） | 開いて Canvas の「Card を生成」を押し、Agent に実装させる | 開始 Card と 3 つの Draft（何を受け取り何を渡すかの計画）だけの状態から、Agent が Card を実装し、実行して確かめる |
| **力学系ギャラリー**（`dynamics-draft`） | 開いて「Card を生成」を押す | 互いに依存しない 6 つの Draft（ローレンツ・アトラクタ、マンデルブロ集合、ロジスティック写像、ライフゲーム、Gray–Scott、二重振り子）を、Agent が helper に手分けさせる。helper ごとに色の違う鶫が自分の Card を同時に書き、実行して確かめ、Agent が最後にまとめて報告する |
| **Live Stream**（`live-stream`） | 実行し、途中で停止（Cancel）する。`interval_ms` / `seed` / `samples` や `plot` の表示幅（`window`）を変えて再実行する | 100 ms 間隔のランダムウォークが WebGPU（Dawn / Metal）の折れ線グラフで滑らかにリアルタイム描画される（直近 60 点）。停止を押すと即座に中断し、その時点までのグラフが残る。再実行すると系列がリセットされ、並列度 1 でも 2 でも 200 点が欠落・順序逆転なく描画される |
