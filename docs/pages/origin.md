# 私にしかない深さ

最初の仕様は開始前からずーーっと温め続けていたものでした。
私が解決しようとしていた課題や、その解決方法は、私が研究をしつつ、AI と触れてきたこの数年の蓄積にあります。

どうやれば AI を積極的に使っても、「この研究は自分のものだ」と楽しめるようなものになるでしょうか?
AI が全てをやってくれる。それって本当に楽しいですか?

人間にしかできないことって何でしょうか?

私はずっと、それに問い続けてきました。

**この文章はもともと、Claude、ChatGPT、Gemini を一切使わず、2026/11/6 の深夜 0 時に私自らの言葉で書いたものです。**
そのあと、長さをまとめるところだけ Claude に手伝ってもらいました。[元の全文](https://github.com/gen740/Tsugumi/blob/4e73814581ee3b37f90019a40efbd6f51decfb72/docs/Origin.md)も残しています。

## 天文物理学という特殊な環境

私は物理学徒として天体物理学を修めています。

宇宙環境特有のノイズを含んでいたり、検出器自体の特性による制限もあり、その解析は簡単なものではありません。
NASA が OSS として公開している解析ソフトウェア [HEASOFT](https://heasarc.gsfc.nasa.gov/docs/software/lheasoft/) は長大で、使用することはとても難しいです。

本来、宇宙はもっと身近にあるべきものです。[宇宙条約の第一条](https://www.jaxa.jp/library/space_law/chapter_1/1-2-2-5_j.html)には、以下の記述があります。

> 月その他の天体を含む宇宙空間の探査及び利用は、すべての国の利益のために、その経済的又は科学的発展の程度にかかわりなく行われるものであり、全人類に認められる活動分野である。

宇宙は全人類のものです。
そして、その宇宙はずっと、あなたの手が届くところにあります。

全てのデータはインターネットで公開され。コマンド一つでデータはダウンロードできます。
ただそれだけで、深宇宙から送られてきたメッセージに触れる。それって本当に素晴しいことだと思います。

でもそれをみんなは知らない。
もっと簡単に宇宙に触れてほしい。もっとみんなに知ってほしい。
だからこそ、私はもっと広くの人にもっと簡単に研究できる環境を届けたかった。

設計で nix という再現性のあるシステムを採用したのも、私が研究を通じて紡ぎ出した私だけの答えです（[gen740/heasoft](https://github.com/gen740/heasoft)）。
ですが、それでも障壁は消えませんでした。

どういうソフトウェアの構成であれば作れるか、どういうアーキテクチャにするべきか、どういう UI にするべきか。
全てずーーーっと私の頭にありながら、それを満たすソフトウェアは自分には壮大すぎて、実現ができない。
この Hackathon に至るまで何度も、数えきれないくらい試作を重ねてきました。

けれども、ずっと あと一歩が足りない。
数ヶ月前の AI では、一つの哲学で一貫したまま、形に作り上げる。その力が足りませんでした。

Claude はその想いを形にしてくれました。
ずーーーっと練り上げて、温め続けていた構想が、たった3日で形になりました。

温め続けていた仕様を貼り付けた時の Claude の最初の言葉が、とても印象に残ります。
「仕様全体は大規模（数ヶ月規模）です。このセッションでどこまでを目標にしますか？」
けれども走り抜けてくれました。

今では自分で作ったものを本当に誇りに思っています。

そして、最後に全ての同志に呼びかけたい。

「人間の知的活動、創造的活動を人間のものとして手放さないためには、どうすればいいのでしょうか?」
