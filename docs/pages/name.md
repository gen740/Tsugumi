# Tsugumi という名前に込めた意味

**Tsugumi** という名前には、[このツールを作ろうと思った理由](philosophy.md)につながる、いくつかの意味を重ねています。

「つぐみ」。

まず重ねたのは、**継ぐこと、積むこと、組むこと**です。
小さな処理のステップを継ぎ、試行錯誤を一つひとつ積み上げる。
そして、それらを組み合わせて、自分の問いを確かめるための実験や解析を形にしていく。
試して、確かめて、また次へつなぐ。それは、研究の営みそのものでもあります。

さらに、「つぐみ」から「つぐむ」、そして音を入れ替えた（音位転換）「つむぐ」へ。
そこには、断片的な試行錯誤をつなぎ合わせ、自分自身の研究を「**紡ぐ**」ための道具でありたいという願いも込めました。
アイコンや画面の中でツグミがくわえている手毬（てまり）と糸も、この「紡ぐ」から来ています。手毬から引き出した一本の糸が、そのまま Card と Card をつなぐ配線になっていきます。

もう一つの由来は、鳥の**ツグミ**です。

ツグミは、冬鳥として日本に渡ってくる全長 24 cm ほどの鳥です。
地上を数歩跳ねては立ち止まり、すっと胸を張ってあたりを見渡す姿で知られています。
一気に走り抜けるのではなく、進んでは立ち止まり、状況を確かめてからまた次へ進む。その姿は、AI とともに試行錯誤を進める研究の歩みとも重なります。

また、冬の間は日本でさえずらず、口を「噤む（つぐむ）」ように見えることからその名がついたという説もあります（[サントリー「日本の鳥百科」](https://www.suntory.co.jp/eco/birds/encyclopedia/detail/1359.html)）。

AI がどれほど饒舌にレポートを語ってくれる時代になっても、言葉の説明だけに頼るのではなく、実際に何を試し、何を確かめたのかというプロセスそのものに語らせたい。
一つひとつの処理をたどり、手を入れ、もう一度動かすことで、研究者自身が納得を積み上げていけるようにしたい。

言葉を重ねて結果を語る時代に、試行の積み重ねを静かに差し出す。
そんなツールの佇まいを、口を噤むツグミの姿に重ねています。
