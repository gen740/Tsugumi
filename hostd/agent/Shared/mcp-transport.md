Before working on a project, call tsugumi_open with its folder (create: true makes a new one). The first successful open returns the shared rules for working on projects; read and follow them before using the other project tools. It opens the project in the Tsugumi web UI, where the person watches each save and run. Project grants apply to every conversation and helper until revoked; attached-folder grants belong to that project too. Project content is unavailable until the person grants access. Request access through the Agent API and wait for their answer. The plugin cannot grant itself access or approve Card permissions. When a call returns grant_required, wait for the person to answer in the page, then retry the same tool with the same arguments.
