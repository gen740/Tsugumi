# macOS UI の構成と操作仕様

現在の macOS 版について、画面階層・役割・操作時の動きをまとめます。描画方式や内部処理は扱いません。

## 画面階層

主要な SwiftUI View と表示領域を示します。Canvas 内の要素はまとめて記載します。

```text
TsugumiApp
+-- メインウインドウ
|   +-- EnvironmentSetupView      初期設定が必要な場合
|   +-- ProjectChooser           Home / Demos
|   `-- WorkflowTabs             プロジェクトを開いた後
|       +-- タブバー             複数の階層を開いた場合
|       `-- Workbench
|           +-- 左: 階層・Card 一覧
|           +-- 中央: CanvasWorkspace > GraphCanvas
|           |   +-- Card / 接続 / グループ / 付箋 / 出力表示
|           |   +-- 上中央: CanvasRunControl
|           |   +-- 右上: CanvasDraftControls、Home へ戻る・チャットのボタン
|           |   `-- 左下: 表示・整理の操作バー
|           +-- 下: 状態表示 / ログ・タイムライン
|           `-- 右: ChatPanel（表示切替・別ウインドウ化）
+-- 詳細ウインドウ
|   +-- CardSettingsEditor       Card 設定
|   +-- CardDatabaseView         定義の検索・編集・配置
|   +-- VersionTreeView          版の履歴（Workflow メニュー、⌥⌘Y）。版に乗せると実行の概要
|   +-- CardExecutionView        実行履歴
|   +-- CardArtifactsView        成果物
|   `-- グループ編集 / 付箋編集 / 可視化の拡大
`-- ApplicationSettings         設定（アプリ全体と、開いているプロジェクト）
```

起動・読込中は進捗表示を画面に重ね、失敗時は理由と再試行を表示します。
Home から新規作成、既存・最近のプロジェクト、Demos を開きます。デモは編集可能なコピーとして開きます。

## メイン画面

```text
+------------------------------------------------------------------+
|                                   [開く] [保存] [チャット]       |
+------------------------------------------------------------------+
| タブ: [プロジェクト] [子 Workflow]                                |
+----------------+------------------------------+------------------+
| Workflow 階層  | [戻る / 現在の階層]          | 会話 / 一覧      |
|                |      [実行・停止] [生成]    |                  |
| Card 定義      |                              | 回答・作業状況   |
|                |    Card -----> Card          |                  |
| 表示中の Card  |    付箋        出力表示      |                  |
|                |                              +------------------+
|                | [倍率 / 全体表示 / 整列 ...] | メッセージ入力   |
| [Workflow設定] +------------------------------+ モデル / 送信    |
|                | 状態 / 保存・同期 / [ログ]   |                  |
|                | ログ・タイムライン（開閉）   |                  |
+----------------+------------------------------+------------------+
```

| 領域 | 役割と主な操作 |
| --- | --- |
| Workflow 階層 | 子 Workflow をタブや別ウインドウで開く。同じ対象のタブは再利用する |
| Card 定義 | 定義フォルダの一覧（定義は Card ごとに 1 つ）。検索・編集し、未配置の定義を Canvas に配置する。他のプロジェクトからコピーできる |
| 表示中の Card | 名前と実行状態を一覧表示。選択・折りたたみが Canvas と連動する |
| Canvas | Card の追加・移動・複製・削除、ポート間の接続・切断、拡大縮小・整列を行う。出力の線は 1 本で、使用中の出力からもう 1 本引くと fork Card が挟まる |
| 実行操作 | 実行・停止、経過時間、進捗、結果を表示。問題一覧から対象 Card やログへ移れる |
| 下部 | 保存・同期状態と件数を表示。全体ログと時間軸上の実行状況を開閉する |
| チャット | Workflow の相談・生成・編集依頼と、その進捗を扱う |

グリッドが有効なとき、ポートは Canvas 上の格子に乗ります。Card の幅は格子の偶数倍に揃え（既定の間隔 20 で 240）、ポートは辺の中央の、幅の半分ほどの範囲に集まります。少ないうちは名前が読める間隔を取り、増えると格子の間隔、その 1/2、1/3 と詰めます。左から右への流れでは、Card のポートは名前と 1 行ずつ並ぶ行のまま、行を格子に揃えます。fork・merge・branch は、ポートが輪郭の上にあるまま、形の幅を格子に合わせます。格子から外れて保存された Card は、移動するまで最寄りの格子に寄せて表示します（保存はしません）。グリッドを切ると元の幅と位置に戻ります。

子 Workflow を表示中でも、実行対象はその文書の Workflow 全体です。
同じ文書を開いたタブ・ウインドウには変更と実行状態が反映されます。

## Canvas の要素

| 要素 | 表示と機能の範囲 |
| --- | --- |
| Card | 名前・状態・入出力・概要・結果を表示。trigger・fork・merge・branch は小さく保ち、概要はホバーで出す。入力 Card は数値を直接編集できる。詳しい設定は別ウインドウで開く |
| 子 Workflow | 内部に Card と接続を持つ。開くと編集する階層が切り替わる |
| グループ | Card を見た目でまとめ、名前・所属・公開出力を編集する。実行順序は変わらず、解除しても Card は残る |
| 付箋 | Markdown の説明を配置し、本文・色・位置・サイズを編集する。実行には参加しない |
| 出力表示 | Card の結果を独立した枠に表示する。移動・拡大・削除ができ、枠を消しても元の Card は残る |

`Shift` + ドラッグの範囲選択は、枠にかかった Card・付箋・出力表示を選びます（Card in Card の中でも同じです）。選んだものはどれをドラッグしても一緒に動き、移動は 1 回の編集として保存され、1 回で取り消せます。グリッドが有効なときは Card に合わせて全体がグリッド単位で動くので、並びは変わりません。Delete では Card と付箋を消し、出力表示だけを選んでいるときは枠を閉じて Card を残します。Card を消すと、その出力表示も消えます。複製とグループ化は Card だけが対象です。

Card の右クリックから設定、履歴、成果物、チャットへの参照追加を行います。
折りたたみは表示だけを変え、Card の実行を無効にはしません。

## Card の編集と結果の確認

左のカテゴリを選ぶと、右の内容が切り替わります。図の右側は各カテゴリの内容を示します。

```text
+------------------+------------------------------------------------+
| Card 設定        | 選択中のカテゴリ       未適用の変更 / 実行状態 |
+------------------+------------------------------------------------+
| 一般             | 名前・概要・パラメータ・実行条件・表示設定     |
| Nix 定義         | 実行環境の定義を編集                           |
| ソース           | ファイル階層 | コード編集                      |
| 入出力           | ポート・記録・成果物の保持設定                 |
| 実行履歴         | 実行一覧 | 呼び出し・入出力・ログ              |
| 成果物           | 出力一覧 | ファイル一覧 | プレビュー           |
| 追加コンテキスト | 処理の意図や補足を文章で編集                   |
|                  +------------------------------------------------+
|                  | メッセージ           [再読込] [適用] [閉じる]  |
+------------------+------------------------------------------------+
```

ソースではファイルの作成・名前変更・削除もできます。
実行履歴と成果物は別ウインドウからも開けます。

```text
実行履歴                              成果物
+------------+----------------------+ +----------------------------------+
| 実行一覧   | 呼び出しを選択       | | 実行 / 呼び出しを選択            |
| 成功・失敗 +----------------------+ +--------+------------+------------+
| で絞り込み | 入出力 / ログ / 情報 | | 出力   | 検索・一覧 | プレビュー |
|            | 選択した記録を確認   | | 一覧   |            |            |
+------------+----------------------+ +--------+------------+------------+
```

Card の種類に応じてカテゴリを絞ります。定義は Card ごとに 1 つ（名前 = ID = 定義フォルダ）で、編集はその Card だけを変えます。
未適用の変更を明示し、「適用」で反映します。画面内の「閉じる」も適用してから閉じます。

Draft は Canvas の上で書きます。`E`（または「+」・右クリックの追加）で出たカード、ダブルクリックしたカードに、内容を直接入力します（別の画面は開きません）。名前はなくてもよく、そのときカードには内容だけが出る（ID は `draft`、`draft-2` のように作られます）。名前を付けるときは内容の上の欄に書き、Return で内容へ移ります。Esc・⌘Return・カードの外のクリックで確定します。ズームが小さいときは読める倍率まで寄せます。
Draft にポートを宣言する操作はありません。線をカードのどこに落としてもつながり、ポートは線に合わせて作られます。ポートは辺の中央にあります。ポートのない辺でも、中央から Draft 自身の線を引き出せる（ポインタを乗せると点が出ます）。線のあるポートから引くと、もう一つポートができます。最後の線を切るとそのポートは消えます。
概要・ポートの名前と用途・追加コンテキストは、右クリックの「設定…」（Card 設定）で編集します。
配線して変更を適用した後、Canvas の「Cardを生成」から現在の階層の Draft を生成し、進捗をチャットで確認します。

## チャット

チャットはセッション一覧と会話を切り替えます。会話には本文・作業状況・入力欄・モデル選択・送信／停止を置きます。
Card や可視化を参照として追加でき、`$` で Skill を選べます。接続設定、履歴検索、再試行、会話の圧縮もここから行います。
会話を圧縮しても全文履歴は残ります。回答の停止と Workflow 実行の停止は別の操作です。

### Canvas の上の Agent

Agent が作業している間、Canvas の上をアイコンの鶫が飛び、何をしているかを見せます（クリックは受けません）。

- **読む**: Agent が Card のファイルや実行記録を読むと、その Card の上辺に止まってのぞき込みます。
- **書く**: Agent の保存で Draft がコードの Card になると、鶫が左から右へ線を引くように Card を書き上げます（書かれていない部分は Draft の点線のまま）。書き終えた Card は、色がゆっくり馴染んでから元に戻ります。値だけ直した Card は、止まってついばみ、色だけが馴染みます。
- **つなぐ**: 書いた Card から出る接続と、新しい接続は、鶫がくちばしで糸を引いて通します。糸はたわみながら伸び、届くとピンと張ります。
- **実行する**: Workflow を実行すると、開始 Card へ飛びます。
- 場面は一つずつ順に流れ、Agent より大きく遅れる「読む」は省きます。ターンが終わると、終わり方に合わせて「できました」「うまくいきませんでした」「止めました」「途中で止まっています」のどれかを言い、しばらくして薄れながら去ります。鶫が表示範囲の外にいるときは、端に向きの印を出します。
- **書いている途中**: Agent が保存（`project_save`）や確認（`project_validate`）の引数にファイルを書いている間、その Card の上に、ファイル名と書かれた最後の数行を出します。モデルから届いた文字だけを、届いた速さで出します。「保存前」と示し、保存に失敗したり止めたりすると消えます（書き上がりの場面は、保存が通ったときだけ流れます）。文字が読めない縮尺や、Canvas にまだない Card では出さず、姿を「表示しない」にしていても出しません。手分けのときは鶫ごとに 1 枚で、枠が鶫の色になります。
- 吹き出しは鶫の頭の上に出ます。ふだんはツール呼び出しから作る短い文（「load を書いています」）です。場面が終わった後は、Agent が今していること（「書き方を調べています」「変更を確かめています」「実行の終わりを待っています」「考えています」）に変わり、終わった場面の文を言い続けません。
- **思考の過程を描く**（入力欄の下の吹き出しのボタン）をオンにすると、Agent の発言とツールの結果を数秒ごとに小さなモデル（Anthropic なら claude-haiku-5-5）へ送って一文に要約し、吹き出しに出します。helper が作業している間も、helper の動きから要約を続けます。Agent とは別に token を使うので、最初にオンにするときに確認します。使った token はボタンの説明に出ます。要約もふだんの文と同じ口調（です・ます、「〜しています」）で、アプリの表示言語で書きます。要約の後に新しい場面が始まれば、場面の文に替わります。
- **手分け**: Agent が作業を helper に分けると（delegate）、helper ごとに鶫がもう 1 羽ずつ現れ、受け持った Card に飛んで同時に読み・書き・実行します。helper の鶫は少し小さく、糸と吹き出しの縁と足もとの影が helper ごとの色で、横に helper の名前が出ます。その間、親の Agent の鶫は大きく金色になり、「Agent」と名前が出るので、どれが親か見分けられます。チャットには helper ごとに 1 行が出て、今していること（終わったらその結果）を示します。
- **配置の整理**: Agent が作業している間、ツールの一歩ごとに少し待ってから、Card の出力の枠（可視化）が他の Card・枠・メモに重なっていないかを見ます。Card とその後ろ（左から右の流れでは下、上から下の流れでは右）に出る枠を 1 つの塊とし、重なった塊を流れと直交する向きに、並び順を保ったまま、ぶつからない所まで押し出します。枠はいつも自分の Card のすぐ後ろに残り、足りない間隔だけが広がります。重なりがなければ何も動きません。移動は普通の配置の変更として保存され、取り消せます。
- 姿は設定の「外観」→「作業中の Agent」で、鶫・点（控えめ）・表示しないから選べます。表示しなくても、Card の書き上がりと糸は見えます。「Tsugumi のアニメーション」が動かさない（またはシステムの視差効果を減らす）のときは、飛ばずに場所を移り、書き上がりはフェードになります。

## 設定

設定は 1 つのウインドウで、左のサイドバーの項目で右の内容を切り替えます。上がアプリ全体、下が開いているプロジェクト（複数開いているときは選ぶ）の設定で、各項目の上に値の保存先を示します。図の右側は各項目の内容を示します。

```text
+------------------------+------------------------------------------------+
| アプリ                 | 選択中の項目（保存先の表示）                   |
+------------------------+------------------------------------------------+
| 一般                   | 言語・並列度・チャット送信キー                 |
| 外観                   | テーマ・グリッド・線の動き / プレビュー        |
| エディター             | インデント幅・ガイド / プレビュー              |
| ショートカット         | 操作とキーの一覧・割り当て変更                 |
| Skills                 | フォルダの追加・有効 / 無効・再読込            |
| API                    | チャットのアカウント・接続設定                 |
| 外部接続               | 接続先・接続状態・コピー                       |
+------------------------+------------------------------------------------+
| このプロジェクト       |                                                |
+------------------------+------------------------------------------------+
| 名前と実行環境         | プロジェクト名・実行環境（tsugumi.json）       |
| Canvas                 | 流れの向き（layout.json）                      |
| データベース接続先     | 名前・URL の一覧、追加・削除（tsugumi.json）   |

| ビルドキャッシュ       | 削除対象の説明・結果                           |
+------------------------+------------------------------------------------+
```

## 状態と操作制限

- 実行中は Card の変更やプロジェクト切替を制限し、進捗・履歴・成果物の閲覧を残します。
- 実行状態と保存・同期状態は分けて表示します。失敗は理由と確認先を示します。
- 同期できない場合は未適用の変更を保持し、コピーと再読込への入口を表示します。
- 未保存の変更を破棄する再読込では確認します。プロジェクト切替は必要な保存が成功してから行います。
- 状態は色に加えてアイコンや文字でも示し、未選択・履歴なし・読込失敗を区別します。
