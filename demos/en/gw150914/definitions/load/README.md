---
title: load
description: Fetch the gravitational-wave data
---

Fetches the H1 and L1 strain data of GW150914 published by GWOSC (4 kHz, 32 s of HDF5) and passes them to the next Card as a folder. Shows the size and SHA-256 of the files fetched.

IPC isolation is off so the native macOS sandbox permits DNS through mDNSResponder.
