# Glowroot

画面を Card で作った小さな放置系ゲームです。Workflow を実行すると、`title/page` が
ゲームのウィンドウ（Dawn のビュー）を開き、続く画面はどれも同じウィンドウに
描きます。芽をクリックして光を集め、自分で光を育てる根を買い、植え直して種を
得て、スキルツリーに使います。3 回目の植え直しのあと「開花」のノードで、
およそ 10 分でゲームが終わります。

矢印はどれも `Turn`（ゲームの状態とウィンドウのセッション）を運びます。実行履歴に
Turn が残るので、ゲームを画面ごとに追えます。`replant/apply` と `skills/validate`
は純粋なルールです。保存された入力でそれだけを再実行して、ルールを確かめられます。
バランスは各 Card の `params.nix` にあります。
